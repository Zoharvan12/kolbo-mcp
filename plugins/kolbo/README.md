# Kolbo.AI

Kolbo.AI brings image, video, music, speech, sound, 3D, document, project, and media-library workflows into ChatGPT and Codex through the public Kolbo MCP server.

## Connect

Install Kolbo.AI from the public plugin directory when its listing is available. Sign in with your Kolbo account and approve access. The plugin uses OAuth and never asks you to paste an API key into chat.

The source bundle connects to the universal MCP endpoint at `https://api.kolbo.ai/mcp`. Developers can still use `npx -y @kolbo/mcp install` for a local stdio setup.

## Example requests

- Generate a cinematic campaign image in my Kolbo project.
- Turn this product image into a short video with sound.
- Show my recent Kolbo media and organize it by project.

Generated work uses Kolbo credits according to the selected model and settings. Review billable or irreversible actions before approving them.
